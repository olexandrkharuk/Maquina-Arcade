# Projecte de Jocs en Python

Aquest projecte conté dos jocs programats amb Python. El primer és Pedra, Paper o Tisora, on el jugador competeix contra el robot. El segon és Endevina el Número, on cal descobrir un número aleatori entre 1 i 100.

El projecte està organitzat en diferents fitxers per separar les funcions i facilitar el manteniment del codi.

## Fitxers del projecte

- main.py: menú principal.
- jocs.py: codi dels dos jocs.
- robot.py: genera les jugades aleatòries del robot.

## Requisits

- Tenir Python 3 instal·lat.
- Tenir els tres fitxers a la mateixa carpeta.

## Com executar el projecte

1. Obrir la carpeta del projecte amb Visual Studio Code.
2. Obrir el terminal.
3. Executar aquesta ordre:

```bash
python main.py
```

4. Seleccionar un joc del menú.
